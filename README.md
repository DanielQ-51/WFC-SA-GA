# Wave-Function-Collapse Betweeness
A repository dedicated to a paper on solving the NP-hard Betweeness problem using metaheuristics and the wave function collapse algorithm. 
<br>
The full paper is avalible in this repository under "Betweeness_Paper (7).pdf"! Please give it a read. To convince you, here is the abstract.

Abstract—The Betweeness Problem is an important NP-hard
problem in computer science and combinatorics. This paper
focuses on a new algorithm, WFC-SA-GA, that approximates
solutions to the optimization version of the Betweeness Problem,
which is also known as the Maximum Betweeness Problem
(MBP). This approach uses the Wave Function Collapse (WFC)
algorithm, which is most popularly seen in procedural generation
in games, to greedily and quickly produce solutions to the
MBP that can be further optimized by other metaheuristical
approaches. In testing against currently established algorithms,
this WFC approach excels in being able to find more optimal
solutions to the MBP than other approaches.
Index Terms—Betweeness Problem, Maximum Betweenness
Problem, Combinatorial Optimization
